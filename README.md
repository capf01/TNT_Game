## Descrição do Jogo

O **TNT Game** é um jogo de ação e desafio no qual o jogador precisa realizar tarefas rápidas e estratégicas, testando sua agilidade e habilidades de tomada de decisão. O jogo é focado em mecânicas de ritmo rápido e interação com elementos típicos da marca TNT Energy Drink, criando um cenário envolvente e energético.

- **Objetivo do Jogo**: Os jogadores devem completar tarefas que exigem rapidez, como coletar latas de TNT Energy Drink, evitar obstáculos e acumular pontos.
- **Público-alvo**: Jovens e adultos que buscam entretenimento enquanto interagem com a marca.
- **Plataforma**: PC ou dispositivos móveis.

## Funcionalidades

- **Controles Personalizados**: Suporte a teclados e controles de gamepad.
- **Jogabilidade**: Mecânica de captura e obstáculos com incremento de dificuldade à medida que o jogador avança.
- **Níveis Dinâmicos**: O jogo possui múltiplos níveis, com cenários e desafios distintos.
- **Pontuação e Rankings**: Sistema de pontos e rankings para aumentar a competitividade.
- **Efeitos Visuais e Sonoros**: Sons e efeitos visuais energéticos, inspirados na marca TNT Energy Drink.

## Tecnologias Utilizadas

- **Unity**: Engine de desenvolvimento principal para criar o jogo.
- **C#**: Linguagem de programação para lógica de jogo.
- **Adobe Photoshop**: Utilizado para criação de assets gráficos.
- **Audacity**: Para edição de efeitos sonoros.

## Instruções de Instalação

Siga os passos abaixo para rodar o projeto localmente:

### Pré-requisitos

- **Unity**: A versão recomendada do Unity é a **2023.x.x**.
- **Git**: Certifique-se de ter o Git instalado em sua máquina.

### Passo a Passo

1. Clone este repositório para o seu computador:

```bash
git clone https://github.com/capf01/TNT_Game.git

2. Abra o projeto no Unity Hub.
Certifique-se de que o projeto esteja configurado para a plataforma desejada (PC, Android, etc.).
3. Execute o jogo no Unity clicando em "Play" na interface da Unity.
Como Executar o Jogo
Após abrir o projeto no Unity, você pode executar o jogo diretamente dentro do editor clicando em Play.
Se você deseja gerar um build para rodar de forma independente, vá em File > Build Settings, escolha a plataforma desejada e clique em Build.
Estrutura do Projeto
A estrutura do projeto segue a organização padrão da Unity:

Assets: Contém todos os arquivos de recursos, como texturas, scripts, sons e cenas.
Scenes: As diferentes cenas do jogo (exemplo: menus, níveis de jogo).
Scripts: Contém a lógica de programação do jogo.
Prefabs: Objetos pré-configurados do jogo, como inimigos, itens, etc.
Animations: Arquivos de animação utilizados no jogo.
